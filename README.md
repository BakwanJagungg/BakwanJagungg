### 👤 Tentang Dava (About Me)

- 🔭 **Fokus Rekayasa**: Arsitektur Desktop Python modern (Win32 Native API), efisiensi algoritma berbasis **C**, dan integrasi embedded hardware **Arduino / IoT**.
- ⚡ **Filosofi Pengembangan**: *100% Local-First, Zero-Bloat, dan High-Precision Execution*. Mengutamakan kestabilan sistem dan performa tinggi tanpa ketergantungan cloud yang berlebihan.
- 💡 **Minat Riset & Eksplorasi**: *Deterministic Web Scraping*, *Low-Latency Network Streaming*, mikrokontroler & sensor IoT, serta model AI inferensi lokal (Ollama Qwen / Phi).
- 💬 **Tanya Saya Tentang**: Pembuatan aplikasi desktop portable `.exe`, otomasi sistem jaringan LAN, kalkulator finansial berbasis C, atau dasar pemrograman IoT Arduino.
